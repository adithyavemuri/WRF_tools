## averaging

### `averaging.mean`

```python
mean(data, dims, *, weighting, weights=None, mask=None)
```

Mean over named dimensions, retaining other dimensions and units.

``weighting`` is explicitly ``uniform``, ``area`` or ``layer``. The latter
two require supplied cell areas or layer thicknesses; no mass weighting is
inferred. A boolean ``mask`` selects an area/layer before reduction.
Non-finite data are excluded from both numerator and denominator. Empty
selections return NaN. Inputs must be co-located with exactly matching
dimension indexes; weights cannot introduce dimensions or negative values.

Source: [src/wrf_tools/averaging.py](../src/wrf_tools/averaging.py).

Method category: numerical reduction. Explicit weights and validity masks; model-index and physical-height means differ.

References/conventions: [NumPy numerical operations](https://numpy.org/doc/stable/reference/index.html); [WRF-ARW v4 Technical Note](https://doi.org/10.5065/1dfh-6p97).

## wind_models

### `wind_models.kaimal_spectrum`

```python
kaimal_spectrum(frequency, *, mean_speed, height, friction_velocity, component='u')
```

Return the neutral surface-layer Kaimal component spectrum.

Near-neutral component variant documented in Risø-R-1506(EN), Eq. (4.5),
https://backend.orbit.dtu.dk/ws/files/7702984/ris_r_1506.pdf (p.35).
It uses u:102/(1+33n)^(5/3), v:17/(1+9.5n)^(5/3), and
w:2.1/(1+5.3n^(5/3)), all multiplied by u*² z/U; n=fz/U.
Kaimal et al. (1972), doi:10.1002/qj.49709841707, is the underlying
family, not a claim that every published coefficient variant is identical.
Frequency is Hz, result is one-sided m2 s-2 Hz-1. This is not IEC Kaimal.

Source: [src/wrf_tools/wind_models.py](../src/wrf_tools/wind_models.py).

Method category: parametric near-neutral spectrum. Explicit Eq.4.5 coefficient variant, not IEC Kaimal. Vertical denominator differs from u/v; see docstring.

References/conventions: [Risø-R-1506(EN), near-neutral component spectra Eq. 4.5](https://backend.orbit.dtu.dk/ws/files/7702984/ris_r_1506.pdf); [Kaimal et al. (1972), surface-layer spectra](https://doi.org/10.1002/qj.49709841707).

### `wind_models.von_karman_spectrum`

```python
von_karman_spectrum(frequency, *, mean_speed, sigma, length_scale, component='u')
```

Return a one-dimensional von Karman velocity spectrum.

Common longitudinal scale L for all components; sigma is the selected
component's standard deviation. Coefficients 71/189 are transcribed directly
from the TurbSim v2 guide Eqs. 27-28, printed p.41. The transverse prefactor
is 2, not the longitudinal 4. Infinite-frequency integrals are approximately
sigma squared (small coefficient-rounding error). This is the legacy
IECVKM family described against IEC 61400-1 edition 2, NOT a claim that
von Karman is specified by IEC 61400-1:2019. SI input; PSD per Hz.

Source: [src/wrf_tools/wind_models.py](../src/wrf_tools/wind_models.py).

Method category: parametric engineering spectrum. TurbSim printed p.41, Eqs.27-28: coefficients 71/189 and transverse prefactor 2. Legacy edition-2 family, not a 2019-standard claim or synthetic field generator.

References/conventions: [TurbSim User's Guide: engineering spectral conventions](https://openfast.readthedocs.io/en/main/_downloads/cb14d3e2d3533d76e405d730fea19846/TurbSim_v2.00.pdf).

### `wind_models.exponential_coherence`

```python
exponential_coherence(frequency, separation, *, mean_speed, decay=12.0)
```

Return Davenport-style exponential ROOT coherence, not squared coherence.

magnitude-squared coherence. This simple model has no IEC length-scale term.

### `wind_models.cheynet_spectrum`

```python
cheynet_spectrum(frequency, *, mean_speed, height, friction_velocity, stability=0.0, component='u')
```

Return the Cheynet marine-boundary-layer velocity spectrum.

Implements the pointed-blunt composite model (Eq. 26) and stable-regime
approximation (Eq. 28) from Cheynet, Jakobsen, and Reuder (2018),
doi:10.1007/s10546-018-0382-2. ``stability`` is the local similarity
parameter zeta. The tabulated coefficients are the 81.5 m values from the
author-supplied open MATLAB implementation migrated into this project.

Frequencies must be positive and are in Hz. With SI inputs, the returned
one-sided PSD is in m2 s-2 Hz-1. The validated coefficient range is
``-2 <= zeta < 2``; no extrapolation is performed.

Source: [src/wrf_tools/wind_models.py](../src/wrf_tools/wind_models.py).

Method category: parametric wind model. Check model-specific stability/coefficient limits. Synthetic data are not TurbSim-quality inflow.

References/conventions: [Kaimal et al. (1972), surface-layer spectra](https://doi.org/10.1002/qj.49709841707); [Cheynet et al. (2018), marine spectra](https://doi.org/10.1007/s10546-018-0382-2).
